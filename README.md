# TI3008C Producto de datos con Streamlit

Proyecto inicial para la actividad individual de Streamlit, GitHub y despliegue.

## Archivo principal

```text
streamlit_app.py
```

## Ejecución en Windows PowerShell

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

## Ejecución en macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m streamlit run streamlit_app.py
```

## Actividad

1. Ejecuta la versión inicial antes de modificarla.
2. Escribe tu nombre dentro de la aplicación.
3. Selecciona una opción de `INSTRUCCIONES_ACTIVIDAD.md`.
4. Implementa y prueba la mejora.
5. Realiza commit y push.
6. Publica la aplicación en Streamlit Community Cloud.
